# Mozaik Mantık

Demir Games Studio — İznik çini temalı bölge mantık bulmacası (Google Play, Flutter).

- `docs/` kurallar, kararlar, araştırma
- `tools/` bulmaca üretici + çözücü (Node), testler
- `data/` 300 seviye, 400 günlük bulmaca, öğretici
- `i18n/` 8 dil (tr, ar, en, de, es, pt, ru, id)
- `design/` görsel kimlik A "Lale Bahçesi" (tokens-a.css), yazı tipleri
- `web/` web önizleme (`python3 web/build.py` → `web/dist/index.html`, test: `node web/test/run.js`)
